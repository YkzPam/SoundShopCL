# Evidencias seleccionadas de SoundShop CL

La serie `final-*` reúne las 36 capturas de la revisión del 6 de septiembre de 2026: nueve vistas, escritorio y móvil, con modo claro y oscuro. El [índice de pantallas](../mockups-prototipo.md) enlaza la selección que corresponde a la entrega actual. El [registro de verificación](../verificacion-entrega.md) precisa qué se comprobó.

Las series `identity-*`, `guest-*` y las demás imágenes conservan estados funcionales y versiones anteriores. No deben interpretarse como una única revisión simultánea. No se eliminaron los archivos históricos; la selección evita mezclarlos con la versión final. El diagrama de flujo se encuentra un nivel arriba, en `docs`, junto con el enlace y el archivo editable.
